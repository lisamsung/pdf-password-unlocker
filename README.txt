PDF 密码解除器 1.1
=================

适用于 Windows 10 / 11，64 位。双击 PDF密码解除器.exe 即可运行。
使用发布的 exe 无需安装 Python，无需联网。

使用方法
1. 拖入 PDF 或文件夹，或者点击“选 PDF”“文件夹”。
   添加文件夹只读取其中直接包含的 PDF，不递归扫描子文件夹。
2. 在“共用密码”输入你已知的打开密码或权限密码。
   不同文件密码不同：选中文件后点击“设置单独密码”，也可以双击文件。
   可多选后一次应用单独密码。密码中的空格会原样保留。
3. 默认将副本保存到原文件所在文件夹，也可选择统一输出文件夹。
4. 点击“解除密码”，完成后点击“打开输出文件夹”。

结果
- 文件名示例：合同_无密码.pdf；重名自动编号为合同_无密码 (2).pdf。
- 文件名接近长度上限时自动缩短，为“无密码”后缀与编号预留空间。
- 原文件保留，已有输出不会覆盖。
- 没有加密的文件显示“无需解除”，不生成重复副本。
- 密码错误或文件损坏时显示“处理失败”；选中文件可查看原因。
  修正密码后再次点击，只重试未完成的文件，成功文件不会重复处理。
- 只有权限限制而没有打开密码的 PDF，可以留空密码处理。
- 支持常见的 RC4、AES-128、AES-256 PDF 密码加密。
  不提供未知密码破解、证书解密或 DRM 移除。
- 直接解除文件加密，保留页面、文字、图片、书签、附件与交互表单。
  不通过打印生成副本。数字签名会因为重新保存而失效；若检测到签名，
  会在该文件的结果详情中提示，原件的签名不受修改。

隐私与运行
- 文件和密码仅在本机处理；程序没有网络请求。
- 密码不写入配置或日志；批次结束后清空输入。
- 窗口较小时可滚动右侧设置；切换到指定输出文件夹时会自动显示选择按钮。
  鼠标滚轮与键盘 Tab 均可访问设置中的控件。
- “停止后续文件”会完成当前文件后停止，尚未处理的文件留在队列中。
- 处理中关闭窗口，会完成当前文件后自动退出。
- 若程序被强制终止，输出目录可能留有 .pdf-unlock-*.tmp 临时文件。
  它不是最终结果；重新处理原件即可，确认程序已退出后可删除临时文件。
- 较新或特殊加密格式可能不受支持，处理失败会保留原件。

快捷键
Ctrl+O：选择文件；Ctrl+Enter：开始处理。
文件列表获得焦点时 Delete：移除所选文件。

源码与构建
需要 Windows 64 位 Python 3.10 或更高版本，包含 Tkinter。
建议先创建独立虚拟环境：python -m venv .venv
激活后运行：powershell -ExecutionPolicy Bypass -File build.ps1
也可安装 requirements.txt 后运行 python app.py。

技术说明
使用 pikepdf / QPDF 解密，Tkinter / tkinterdnd2 提供桌面和文件拖放，
PyInstaller 打包。随附第三方许可证位于 licenses 文件夹。
官方项目：https://github.com/pikepdf/pikepdf
官方文档：https://pikepdf.readthedocs.io/en/latest/topics/security.html
拖放组件：https://github.com/Eliav2/tkinterdnd2
打包工具：https://pyinstaller.org/
